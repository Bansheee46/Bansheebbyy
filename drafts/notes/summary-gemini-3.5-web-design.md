# Gemini 3.5 для веб-дизайнеров — саммари

## Суть
Viktor Oddy показывает, как создавать дорогие интерактивные сайты (на $50k) с помощью **Google AI Studio** и модели **Gemini 3.5** — бесплатно, за один промпт, без Framer/Webflow.

## Ключевые инструменты
- **Google AI Studio** (Gemini 3.5) — генерация кода сайта
- **ChatGPT (GPT-4o)** — генерация изображений (день/ночь)
- **Claude** — очистка и улучшение промптов
- **SeaArt 2.0 / Kling 3.0** — анимация статичных изображений
- **Pinterest / Dribbble** — визуальные референсы

## Пошаговый процесс

### 1. Подготовка изображений
- Найти референс на Pinterest (ориентироваться на популярность/лайки)
- Сгенерировать изображение в ChatGPT (8K)
- Создать night-view версию тем же промптом

### 2. Генерация промпта для сайта
- Скопировать стиль шрифтов/цветов с MotionSites или другого примера
- Отправить в Claude для очистки (оставить только цвета, шрифты, позиции)
- Вставить очищенный промпт в Google AI Studio

### 3. Hero-секция
- Загрузить изображение как фон (без оверлея)
- Добавить blur-эффект внизу страницы (скриншот промпта → AI)
- Создать toggle day/night (референс с Dribbble → AI)
- Добавить transition между режимами

### 4. Анимация фона
- Записать скриншот референс-видео с Pinterest
- Загрузить в SeaArt 2.0/Kling 3.0 как reference
- Сгенерировать видео-анимации для day и night режимов
- Заменить статичные изображения на видео в Gemini

### 5. Остальные секции
- Попросить Gemini построить 6-7 секций для AI design agency
- Улучшать каждую секцию вручную (дизайнерский ввод важен!)
- Примеры: карточки с hover-эффектом, горизонтальный scroll, isometric-дизайн

### 6. Исправление loop-видео
- Использовать промпт для "boomerang" эффекта (видео проигрывается вперёд, затем назад)
- Убрать резкий обрыв при зацикливании

## Маркетинг
- Записать скролл сайта через screen recording
- Опубликовать в Twitter с тегом инструментов (Gemini 3.5, SeaArt 2.0)
- Отметить @viktoroddy — если дизайн качественный, он может repost/DM

## Главный инсайт
> AI — это не замена дизайнеру, а инструмент. Качество результата зависит от дизайнерского ввода: референсов, уточнений, ручной доработки. "If it looks like AI designed it — you need human input."
